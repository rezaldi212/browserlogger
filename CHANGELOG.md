# Changelog

## [v1.0.0] - 2026-06-01

### Added
- Initial public release of Browser Logger.
- Qt-based browser window with a live logging panel.
- Automatic capture of navigation events, load status, visible page text, and selected text.
- Auto-save of session logs under `logs/`.
- MIT license.

### Changed
- Refined README for public release.
- Expanded `.gitignore` for common Python and Qt build artifacts.
